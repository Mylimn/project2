产品介绍

商品图散落在详情页里，保存下来却很麻烦

详情页为了排版，会把同一件商品的图片分散在轮播、参数图、详情长图和买家秀里， 还混着 logo、图标、占位图。手动右键另存不仅费时，导出的格式也常常不统一。

图片分散

轮播图、详情长图、背景图各在一处，靠肉眼翻找很容易漏图。

无法批量保存

右键逐张另存既打断浏览节奏，也容易把页面的装饰图一起存下来。

格式不统一

jpg、webp、png 混在一起，后续上传或排版时还要逐个转换。

图提取把这三件事合并成一次点击：扫描当前页面 → 过滤装饰图 → 统一转成 PNG， 让你把时间花在选图上，而不是反复右键和格式转换上。

核心功能

从扫描到下载，六个步骤一次完成

所有处理都在本地浏览器里完成，不上传页面内容，也不需要额外账号。

一键提取

自动扫描页面所有商品图，兼容 srcset 与懒加载，滚动触发后统一收集。

智能过滤

自动排除图标、logo、占位图、1x1 像素图与营业执照等站点界面图。

集中预览

新标签页网格展示全部图片，附尺寸与来源标签，数量一目了然。

自由勾选

支持全选、反选与按最小尺寸筛选，只下载本次真正需要的图片。

统一 PNG

jpg、webp、gif 自动通过 canvas 转换为 PNG，尺寸与透明度保持不变。

批量下载

一键保存到浏览器下载目录，文件名自动编号为 商品图_001.png。

安装步骤

四步装好，全程不超一分钟

图提取是未上架商店的本地扩展，需要以「加载已解压的扩展程序」方式安装。 安装完成后刷新已打开的商品页即可生效。

  1. 1

    下载并解压插件

    从项目仓库获取源码压缩包，解压到任意本地文件夹，确认文件夹中包含 manifest.json。

  2. 2

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    打开页面右上角的 开发者模式 开关。

  4. 4

    加载已解压的扩展程序

    点击 加载已解压的扩展程序，选择第 1 步解压出的文件夹即可。
